# Contributing to RoomRent

First off, thank you for considering contributing to RoomRent! Let's build a trusted marketplace for rooms together.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and constructive in all interactions.

## How to Contribute

Whether it's a bug fix, new feature, or a documentation improvement, we welcome your contributions.

### Development Workflow

1. **Fork the Repository** and clone it to your local machine.
2. **Setup your environment:**
   - Install dependencies with `pnpm install`
   - Setup Supabase (follow the quickstart in `README.md` to configure `.env.local`)
3. **Run the development server:**
   - `pnpm dev`
4. **Create a branch** for your feature or fix.
   - Example: `feature/add-profile-editing` or `fix/404-error-page`
5. **Make your changes**. Make sure your code follows the existing style, which relies heavily on Tailwind CSS, Next.js App Router, and our chosen UI libraries (shadcn/ui, DaisyUI, Flowbite).
6. **Commit your changes**. Please use clear, descriptive commit messages.
7. **Push to your fork** and submit a Pull Request.

### Submitting a Pull Request (PR)

- Provide a clear PR title and description. Explain the problem and the solution.
- Before submitting, make sure the project builds and runs without errors.
- We will review your PR and may request changes before merging.

### Bugs and Features

- **Reporting Bugs:** Please open an issue. Make sure to describe the bug, how to reproduce it, and the environment (browser, OS).
- **Proposing Features:** Check `docs/MVP.md` and our roadmap. If your feature aligns with our goals, please open an issue to discuss it first.

### Troubleshooting

If you run into issues during development, check `docs/TROUBLESHOOTING.md`.
